# Gestor de Tareas CLI

Aplicación de consola desarrollada en Python para administrar tareas.

## Requisitos
- Python 3.8 o superior.

## Ejecución
Abra una terminal en esta carpeta y ejecute:

```bash
python app.py
```

## Funciones
- Agregar tareas.
- Listar tareas.
- Completar tareas.
- Eliminar tareas.

Las tareas se guardan en memoria mientras la aplicación está abierta.
